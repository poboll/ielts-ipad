## 适配范围

- iPad 全屏横屏使用；只声明 `Landscape Left` 与 `Landscape Right`，即横屏状态下可翻转 180°；**不支持竖屏界面**。
- 禁止网页双击/捏合缩放，并限制页面整体横向溢出。
- HTTPS 外链交由系统浏览器打开。
- 当前已通过 13 英寸 iPad Pro 模拟器的横屏基础验收。2021 款 11 英寸 iPad 真机尚未验收，不能据此承诺所有尺寸与题型都已验证。

模拟器的机身方向可以被手动旋转；这不等于应用支持竖屏。将模拟器强制设为竖屏时，iOS 可能以黑边/兼容画布显示仍保持横屏的应用。验证本项目方向时，请在模拟器 **Device → Orientation** 中选择 `Landscape Left` 和 `Landscape Right`。

## 下载与安装

> **下载 ≠ 签名 ≠ 安装。** GitHub Releases 用于保存和下载文件，不会自动给 IPA 签名；部署一个网页，也不会让普通 iPad 自动接受未签名安装包。

### 先选择安装方式

| 使用环境 | 操作方式 | 当前项目是否已经实测 |
| --- | --- | --- |
| iPad 已装 TrollStore，且系统兼容 | 下载 IPA，再交给 TrollStore 安装 | 安装包候选；未完成真机安装验收 |
| 普通 iPad，没有 TrollStore，有 Mac / Windows 电脑 | 用 Sideloadly、AltStore Classic 等重新签名并侧载 | 尚未实测本 IPA 的该路径 |
| 使用爱思助手 | 先对 IPA 签名，再导入安装已签名的文件 | 尚未实测；仅提供官方工具流程参考 |
| 只有 iPad，想用在线签名网站 | 需有适用于该设备的有效签名、描述文件及相应安装服务 | 本项目不提供在线签名服务 |
| 想在 Safari 点一下直接安装 | 当前未签名包不能在普通 iPad 上这样安装 | 本项目没有提供 OTA 一键安装 |
| Mac / Windows 上做题 | 从[官方上游](https://www.9fnnn.com/)下载对应桌面客户端 | 不使用本项目 IPA 作为桌面安装包 |

以上侧载流程是安装工具的使用说明，**不是本 IPA 已在各工具上安装成功的承诺**。当前验证结果主要是 13 英寸模拟器基础运行；具体设备安装、签名兼容性、登录与做题流程仍需真机验收。

### 1. 下载 IPA

1. 使用有仓库访问权限的 GitHub 账号登录。
2. 打开 [Releases](https://github.com/poboll/ielts-ipad/releases)，展开对应版本的 **Assets**。
3. 下载 **`ielts-ipad-v1.0.0-landscape.ipa`**，不要把 `Source code (zip)` 当作安装包。
4. iPad 用户可在 Safari 下载后保存到“文件”；也可使用个人 iCloud Drive 的 `Downloads` 副本。文件名不同不影响内容，但应核对校验值。

当前 IPA 的 SHA-256：

```text
7522a4d9b32e771e5b30e42d73d415bed56d2c1622b878ef71d172f103429756
```

Mac 可用 `shasum -a 256 <文件路径>`，Windows PowerShell 可用 `Get-FileHash <文件路径> -Algorithm SHA256` 核对。校验值只用于确认文件完整性，不代表已经获得 Apple 签名或通过安全审查。

### 2. 已有 TrollStore

1. 先确认已安装可用的 TrollStore，并查看 [TrollStore 官方项目](https://github.com/opa334/TrollStore)的系统支持范围。它**不是所有 iPadOS 版本都支持**的安装器；本 IPA 另要求 iPadOS 16.0 或以上。
2. 在“文件”中找到下载的 IPA，通过共享菜单交给 TrollStore；或在 TrollStore 内选择本地 IPA 安装。
3. 确认安装后，从主屏幕打开“九分学长雅思”，横屏使用；允许在两个横屏方向间翻转 180°。
4. 按应用提示使用自己的账号登录，先验证登录、题库、音频及练习流程。

Private Release 链接需要 GitHub 身份验证，因此这里采用**先下载本地 IPA，再交给 TrollStore**的方式，不提供依赖私有下载地址的浏览器一键安装按钮。卸载或维护 TrollStore 安装的应用，请按 TrollStore 官方说明操作。

### 3. 没有 TrollStore：电脑重新签名侧载

未签名 IPA 可以作为签名工具的输入文件，但**必须先完成有效签名**，普通系统才可能安装。电脑在这里是安装工具的运行环境，应用最终安装到连接的 iPad，不是安装到电脑桌面。

#### Sideloadly

1. 从 [Sideloadly 官方网站](https://sideloadly.io/)获取工具，并按其说明准备设备连接环境。
2. 用数据线连接 iPad，解锁，并在设备上确认信任此电脑。
3. 在工具中选择实际连接的 iPad，导入本项目 IPA，使用自己的 Apple 账号按工具流程签名和安装。
4. 如果出现“未受信任的开发者”，按系统提示在“设置 → 通用 → VPN 与设备管理”中确认自己用于签名的开发者。
5. 开发签名侧载在 iPadOS 16 或以上可能需要“开发者模式”；按系统提示在“设置 → 隐私与安全 → 开发者模式”启用、重启并确认。若入口未出现，先完成工具要求的配对/签名流程，参考 [Apple 开发者模式文档](https://developer.apple.com/documentation/xcode/enabling-developer-mode-on-a-device)。

Sideloadly 官方说明：免费账号签名通常只能使用 **7 天**；需在到期前续签或重新侧载。付费开发者账号签名的可用时长也受证书、描述文件和设备资格限制，不能承诺永久有效。自动刷新通常仍需要可用的电脑连接环境。详见 [Sideloadly FAQ](https://sideloadly.io/faq.html)。

#### AltStore Classic

1. 按 [AltStore 官方教程](https://faq.altstore.io/)在 Mac / Windows 上配置 AltServer，并把 **AltStore Classic** 安装到 iPad。
2. 按其要求完成电脑信任、开发者信任和开发者模式设置。
3. 将 IPA 保存到 iPad“文件”，在 AltStore 的 **My Apps** 页通过导入入口选择 IPA，按提示完成签名侧载。
4. 按官方要求保持 AltServer 可连接，并定期刷新应用。

免费账号通常需要每 **7 天**刷新，且存在同时安装的侧载应用数量限制；详见 [AltStore Classic 使用说明](https://faq.altstore.io/altstore-classic/your-altstore)。这里说的是 **Classic 侧载方案**，不表示本项目已经提交到 AltStore PAL、App Store 或 TestFlight。

更新与续签时尽量保持相同账号及工具生成的 Bundle ID，先备份重要数据。不要为了重装随意删除旧应用；不同签名身份或 Bundle ID 可能导致原应用数据无法沿用。

### 4. 爱思助手：先签名，再导入

爱思助手不是“忽略签名检查”的安装器。仅把本项目未签名 IPA 拖进去，**不能保证普通 iPad 可安装**。

按[爱思助手官方 IPA 签名教程](https://www.i4.cn/news_detail_38195.html)的思路：

1. 从爱思助手官方渠道获取客户端，连接并信任自己的 iPad。
2. 若当前平台/版本提供该功能，在“工具箱”中打开 **IPA 签名 / IPA 文件签名**，导入 IPA；不同版本菜单可能不同。
3. 选择自己的有效证书与匹配的描述文件，或使用工具支持的个人账号签名流程。签名涉及目标设备时，确认设备标识匹配。
4. 执行签名，找到工具输出的**已签名 IPA**；不要误选原始未签名文件。
5. 使用客户端的应用导入/安装功能，将已签名文件安装到目标 iPad。
6. 按系统提示完成开发者信任及必要的开发者模式设置，再打开应用。

签名有效期、证书撤销、目标设备不匹配等都可能造成无法安装或“掉签”。若客户端没有签名入口或签名失败，不应假设“直接导入”可以绕过检查；请查看[爱思官方签名常见问题](https://www.i4.cn/news_detail_40956.html)。上述官方教程发布较早，具体入口和账号验证方式请以当前工具为准。

### 5. 在线签名与网页一键安装

**目前没有部署在线签名服务、OTA 安装页面或网页运行版。**

- **在线签名网站**：本质是服务商对 IPA 重新签名，再给出安装文件或入口；不是上传未签名包后由 Safari 直接运行。需核实签名方式、目标设备资格、证书有效期、撤销风险及隐私条款。本项目不推荐或担保任何付费签名商，也不承诺此路径已验证。
- **网页 OTA 安装**：例如 Apple 的企业内部应用部署，需要相应有效签名、符合分发资格的应用、HTTPS 托管及安装清单。企业分发只用于符合资格的组织内部场景，不是自制项目对外任意分发的通用办法；其他签名方式也各有设备和分发限制。仅加一个 `itms-services` 按钮，不能让未签名包变得可安装。参考 [Apple 内部应用分发说明](https://support.apple.com/guide/deployment/distribute-proprietary-in-house-apps-depce7cefc4d/web)。
- **Private GitHub Release**：下载依赖授权登录，不能假定 iPad 的系统安装器会继承 Safari 的 GitHub 登录状态。不要把 GitHub Token 放进网页、安装清单、URL 或客户端中来解决访问问题。
- **TrollStore 浏览器安装入口**：即使使用它支持的 URL Scheme，也需要设备已经具备兼容的 TrollStore；它不是为普通 iPad 提供免签名安装。本项目当前不提供此入口。

不要向不可信网站提交 Apple 账号密码、双重验证代码、GitHub Token、证书私钥或证书密码，也不要安装来历不明的设备管理描述文件。证书材料和设备标识不应提交到 Git 仓库。

## GitHub 配置能做什么？

| 功能 | 能做的事 | 不能替代的事 |
| --- | --- | --- |
| Releases | 保存 IPA、版本说明和下载入口 | Apple 签名、目标设备授权 |
| Actions | 在源码、资源、构建环境齐备时自动构建；有合法签名材料时可配置签名流程 | 凭空生成可用证书、绕过 iPadOS 安装检查 |
| Pages | 托管静态说明/下载页面；满足条件时可作为安装入口的一部分 | 把 IPA 变成桌面应用、网页应用或免签安装包 |

当前 GitHub 仓库只保存说明与截图，IPA 放在 Release；**没有提交完整构建源码/官方资源，也没有配置 Actions、签名证书或 Pages**。因此当前不能通过点击 GitHub 部署按钮重建或在线签名本应用。

以后若配置自动构建，需要先准备有权使用的构建输入；如配置签名，还需要正确的证书、私钥、描述文件和设备资格，且应使用受控的 Secrets 等机制管理材料，不能把它们写入代码或日志。本次只补充文档，没有部署这些服务。

特别注意：[GitHub Pages 文档](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages)说明，**私有仓库不等于 Pages 网站一定私有**；默认发布的网站可能公开，访问控制与套餐/组织配置有关。本项目保持 Private，不为了“一键安装”公开安装包或创建公开镜像。

### 电脑使用与网页使用的区别

- **Mac**：到[官方网站](https://www.9fnnn.com/)下载官方 Mac DMG，打开后按其指引将应用安装到“应用程序”。上述 `0.9.17-rc.2-universal.dmg` 是本项目当前构建依据，不要求桌面用户退回旧版本。
- **Windows**：到同一官方入口获取 Windows 客户端；本项目不提供 Windows 安装包。
- **本项目 IPA**：面向 iPad，不是通用 Mac/Windows 安装包。部分 Apple Silicon Mac 可运行兼容的 iPad 应用，但本项目没有做桌面侧载适配或验收；电脑使用请优先选择官方桌面版。
- **网页运行 / PWA**：不是把 IPA 上传到 GitHub Pages 就能使用。需要另行移植原生桥接、页面资源和服务访问逻辑，并验证登录、网络来源限制及音频行为。本项目没有提供这个版本。

## 安装后快速验收

1. 横屏打开应用，分别检查两个横屏方向，确认只允许横屏内 180° 翻转。
2. 双击及捏合页面，确认不触发整页放大；检查页面最右侧区域无需横向拖动即可访问。
3. 切换应用内主题色，检查顶部按钮、题目区域和弹窗；点击外部文档链接，确认交给系统浏览器。
4. 用自己的账号验证登录、题库加载、音频播放及练习流程。截图/模拟器成功不能代替这些真机验收。

若应用突然无法打开，先排查签名到期/撤销、开发者信任、开发者模式和设备系统兼容性；不要默认是题库服务故障。页面能打开但数据加载失败时，再检查网络、账号与官方服务状态。
